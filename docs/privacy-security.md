# 隐私与安全边界

## 输入

服务接受两种内容来源：

- 公开的 `https://chatgpt.com/s/t_<32 位小写十六进制>` 链接（拒绝 HTTP、凭据、端口、查询参数、片段、IP 地址、编码绕过和其他主机）；
- 纯文字，最多 2000 个 Unicode 字符，按 code point 计数，拒绝空白。

不接受任意网页地址、登录 Cookie 或私有聊天。

## 浏览器网络

ChatGPT 来源会启动隔离的无登录态 Chromium 打开校验后的规范 URL。每个渲染任务使用独立浏览器上下文，任务结束即关闭。纯文字来源不发起任何外部导航，只在内存中渲染。

## 抽取与净化

ChatGPT 抽取的内容 HTML 经过阅读白名单净化：移除按钮、表单、脚本、内联事件和危险协议；只保留段落、标题、列表、代码、引用、表格、链接和图片等阅读结构。纯文字在渲染前严格 HTML 转义，绝不作为可执行 HTML。

## 数据处理

- 不建立用户账号、历史记录或持久存储。
- 不加载或保存用户登录 Cookie。
- 每个请求使用隔离浏览器上下文，任务结束即关闭。
- 链接、对话正文、文字内容和 PNG 只存在于当前请求内存与返回的响应中。
- 所有图片和错误响应均不缓存（`Cache-Control: no-store`）。

## 日志

不记录完整 URL、分享 ID、对话正文、文字内容、HTML、Cookie、浏览器 console 或图片字节。错误响应只返回稳定错误码，不回显输入。

## 公网保护

公开部署时滥用防护放在 Cloudflare 边缘（速率限制），或用 Cloudflare Access 限定受邀身份；应用内不写分布式限流或 Turnstile。
