# 隐私与安全边界

## 输入

服务只接受公开的 `https://chatgpt.com/s/t_<32 位小写十六进制>` 链接。拒绝 HTTP、凭据、端口、查询参数、片段、IP 地址、编码路径绕过和其他主机。

## 浏览器网络

导航与子资源使用静态 allowlist。主文档只能访问已校验的规范 URL；每次 redirect 重新校验。拒绝私网、回环、链路本地、IPv6 ULA 和云元数据地址。最终子资源 host 只能来自不保存内容的真实浏览器验证。

## 数据处理

- 不建立用户账号、截图历史或持久存储。
- 不加载或保存用户登录 Cookie。
- 每个请求使用隔离浏览器上下文，任务结束即关闭。
- PNG 只存在于当前响应和用户浏览器 Blob URL 中。
- 所有图片和错误响应均不缓存。

## 日志

只允许记录请求 ID、平台、阶段耗时、输出模式、尺寸、字节数和错误码。禁止记录完整 URL、分享 ID、正文、HTML、Cookie、浏览器 console、图片字节或包含这些字段的异常消息。

## 公网保护

Cloudflare 公开版本必须在浏览器启动前完成 Turnstile、WAF、速率限制和严格并发门禁。任何安全关键浏览器拦截能力未通过 staging 实测时，不得上线截图接口。
